# 2026-11-19 更新

本次新增 19 篇（A 4 / B 7 / C 8）。

- **A · 推理RL算法** [Rethinking the Trust Region in LLM Reinforcement Learning](https://openreview.net/forum?id=f4g8zblbwp) [arXiv](https://arxiv.org/abs/2602.04879)（ICML 2026）：DPPO：以策略散度的近似估计替代 PPO 单样本比率裁剪，缓解低概率 token 过度惩罚与高概率 token 约束不足问题；ICML 2026 录用且开源，可作为 PPO/GRPO 裁剪项的低代价替换
- **A · 奖励模型/PRM** [VisualPRM: An Effective Process Reward Model for Multimodal Reasoning](https://arxiv.org/abs/2503.10291)（arXiv 2025）：开源 8B 多模态过程奖励模型及 VisualPRM400K 数据与 VisualProcessBench 基准，BoN 下使 InternVL2.5-78B 在七个多模态推理基准平均提升 5.9 分，可直接用于测试时重排序
- **A · 训练系统/效率** [Stabilizing MoE Reinforcement Learning by Aligning Training and Inference Routers](https://arxiv.org/abs/2510.11370)（arXiv 2025）：Rollout Routing Replay（R3）：记录推理引擎的专家路由并在训练时回放，显著降低训推策略 KL、缓解 MoE RL 训练崩溃，且不降低训练速度，实现改动小、易于接入现有框架
- **A · 多模态RL** [MM-RLHF: The Next Step Forward in Multimodal LLM Alignment](https://openreview.net/forum?id=ULJ4gJJYFp) [arXiv](https://arxiv.org/abs/2502.10391)（ICML 2025）：发布 12 万对细粒度人工标注多模态偏好数据，并提出先生成评语再打分的 Critique-Based RM 与动态奖励缩放；ICML 2025，数据与模型可直接用于 MLLM 对齐
- **B · 推理RL算法** [Self-Evolving Curriculum for LLM Reasoning](https://arxiv.org/abs/2505.14970)（arXiv 2025）：将课程选择建模为非平稳多臂老虎机，以策略梯度绝对优势作为即时学习增益信号与 RL 同步更新课程，在规划、归纳推理与数学上提升难题与分布外泛化，额外开销低
- **B · 推理RL算法** [Rewarding the Unlikely: Lifting GRPO Beyond Distribution Sharpening](https://aclanthology.org/2025.emnlp-main.1298/) [arXiv](https://arxiv.org/abs/2506.02355)（EMNLP 2025）：指出 GRPO 存在偏向高概率轨迹的秩偏差而仅做分布锐化，提出 unlikeliness reward 上调罕见正确解的权重，在形式化定理证明上改善 pass@N
- **B · 推理RL算法** [Rethinking Entropy Interventions in RLVR: An Entropy Change Perspective](https://aclanthology.org/2026.acl-long.1436/) [arXiv](https://arxiv.org/abs/2510.10150)（ACL 2026）：推导单步 token 级熵变的紧近似并统一解释现有熵干预方法，据此提出按估计熵变自适应重加权 token 的 STEER，在 6 个数学与 3 个代码基准上缓解熵坍缩并优于基线
- **B · RLHF/偏好对齐** [Taming Overconfidence in LLMs: Reward Calibration in RLHF](https://openreview.net/forum?id=l0tg0jzsdL) [arXiv](https://arxiv.org/abs/2410.09724)（ICLR 2025）：揭示 PPO 所用奖励模型偏好高置信度表述并导致言语化过度自信，提出带校准奖励建模/校准奖励计算的 PPO-M 与 PPO-C，在不损失性能的前提下改善校准
- **B · 奖励模型/PRM** [Black-Box On-Policy Distillation of Large Language Models](https://arxiv.org/abs/2511.10643)（arXiv 2025）：GAD：以判别器作为与学生共同演化的在策略奖励模型，实现仅凭教师文本输出的黑盒在策略蒸馏，稳定优于序列级知识蒸馏；对抗训练稳定性与跨任务通用性仍待验证
- **B · 多模态RL** [Direct Preference Optimization of Video Large Multimodal Models from Language Model Reward](https://aclanthology.org/2025.naacl-long.30/) [arXiv](https://arxiv.org/abs/2404.01258)（NAACL 2025）：以详细视频字幕作为视频内容代理，由纯文本 LLM 对视频问答打分构造偏好对再做 DPO，低成本获得视频 LMM 奖励信号，NAACL 2025
- **B · 多模态RL** [VideoRFT: Incentivizing Video Reasoning Capability in MLLMs via Reinforced Fine-Tuning](https://openreview.net/forum?id=3pORFyKzh1) [arXiv](https://arxiv.org/abs/2505.12434)（NeurIPS 2025）：构建 102K 视频 CoT 与 310K RL 数据，并在 GRPO 中引入文本推理与视觉证据一致的语义一致性奖励，NeurIPS 2025；数据可复用但收益依赖特定视频基准
- **C · Agent/工具RL** [Training-Free Group Relative Policy Optimization](https://arxiv.org/abs/2510.08191)（arXiv 2025）：以组内语义优势迭代提炼经验知识作为上下文先验，无参数更新提升 API 模型的数学与搜索智能体表现；实质为经验库式上下文学习而非策略优化，命名易引起误解，但落地成本低
- **C · 多模态RL** [Improve Vision Language Model Chain-of-thought Reasoning](https://aclanthology.org/2025.acl-long.82/) [arXiv](https://arxiv.org/abs/2410.16198)（ACL 2025）：以 GPT-4o 生成 CoT 进行 SFT，再以短答案作为结果信号构造正负对做 DPO；主体为蒸馏式 SFT，RL 部分为常规偏好优化
- **C · 多模态RL** [R1-Omni: Explainable Omni-Multimodal Emotion Recognition with Reinforcement Learning](https://arxiv.org/abs/2503.05379)（arXiv 2025）：将 RLVR 应用于音视频全模态情感识别，提升准确率与分布外泛化，属领域专用应用
- **C · 多模态RL** [X-Omni: Reinforcement Learning Makes Discrete Autoregressive Image Generative Models Great Again](https://arxiv.org/abs/2507.22058)（arXiv 2025）：以 RL 缓解离散自回归图像生成的伪影与指令遵循问题，7B 统一模型图像生成表现强，但面向图像生成方向且依赖扩散解码器，对 LLM 后训练的参考价值有限
- **C · 多模态RL** [Visionary-R1: Mitigating Shortcuts in Visual Reasoning with Reinforcement Learning](https://arxiv.org/abs/2505.14677)（Trans. Mach. Learn. Res. 2025）：以 caption-reason-answer 格式和纯 RL 训练缓解视觉推理捷径学习，无需 CoT 标注；超越 GPT-4o 等的结论仅限所选基准，需审慎看待
- **C · 分析/实证** [Reinforcement Learning with Verifiable Rewards: GRPO's Effective Loss, Dynamics, and Success Amplification](https://arxiv.org/abs/2503.06639)（arXiv 2025）：将 GRPO 在二值奖励下等价为加权对比损失，并给出不同奖励归一化与 KL 正则形式下最优策略的显式迭代及成功率放大分析，理论参考价值高，实证较少
- **C · 分析/实证** [The Invisible Leash: Why RLVR May or May Not Escape Its Origin](https://arxiv.org/abs/2507.14843)（arXiv 2025）：提出经验支撑动态框架逐题比对 RLVR 前后可验证解，发现在给定采样预算下支撑收缩多于扩张、与 pass@1 提升并存，是理解 RLVR 能力边界的实证参考
- **C · 分析/实证** [The Path Not Taken: RLVR Provably Learns Off the Principals](https://arxiv.org/abs/2511.08567)（arXiv 2025）：参数空间分析显示 RLVR 更新避开主奇异方向、谱漂移小，与 SFT 处于不同优化区间，提示直接套用 SFT 时代 PEFT（稀疏微调、LoRA 变体）可能失效；理论分析为主，无新训练方法
